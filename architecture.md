# Архитектура системы: Сервис задач

## 1. Контекст (C4 Level 1)
Пользователь взаимодействует с системой через веб-браузер. Система предоставляет API для управления задачами. Внешних систем пока нет.

## 2. Контейнеры (C4 Level 2)
Система состоит из следующих контейнеров (Docker):
- Gateway (Nginx): Единая точка входа, маршрутизация, лимитирование запросов.
- API (2 реплики): Приложение на .NET, обрабатывающее бизнес-логику.
- Database (PostgreSQL): Хранение данных.
- Cache (Redis): Кэширование.

## 3. Компоненты (C4 Level 3)
Внутри API:
- Контроллеры: Обработка HTTP-запросов.
- Сервисы: Бизнес-логика.
- Репозитории: Работа с базой данных.
